隱私權保護政策 (Privacy Policy)
最後更新日期：2026年3月2日

感謝您使用「AI 智能記帳管家」。

我們非常重視您的隱私，為了讓您安心使用本服務，特此說明我們的隱私權保護政策，以保障您的權益：

一、 資料收集之類別與方式
當您與本服務互動時，我們會收集以下資訊：

LINE 帳號資訊：包含您的內部識別碼 (User ID)、顯示名稱及大頭照，用於辨識您的帳本歸屬。

帳務資訊：您主動輸入的記帳對象、金額、品項及消費日期。

對話資訊：您與 AI 管家的聊天文字內容，用於提供對話回覆。

二、 資料使用之目的
我們所收集的資料僅用於以下用途：

核心功能提供：計算您的帳務總額、產出明細報表及 QuickReply 快速回覆建議。

智慧回覆優化：透過 AI 技術（如 Google Gemini）解析您的語法，以自動辨識記帳內容。

系統優化：分析匿名化後的錯誤記錄 (Logs)，用以修復系統漏洞。

三、 第三方服務與資料分享
本服務承諾絕不將您的個人資料提供給無關的第三方，唯下列情況除外：

AI 處理：您的對話文字會傳送至 Google Gemini API 進行語意分析。我們不會將您的 LINE User ID 直接提供給 Google。

技術基礎建設：資料儲存於受保護的雲端資料庫（如 Aiven MySQL），該服務符合國際安全標準。

四、 資料安全與保存
加密傳輸：所有資料傳輸均經過 SSL/TLS 加密保護。

儲存期限：我們將持續保存您的記帳紀錄直到您主動要求刪除，或本服務停止營運。

五、 使用者權利 (您可以怎麼做)
您可以隨時行使以下權利：

查詢與檢視：在聊天視窗輸入「查帳」即可檢視目前儲存的所有總額。

要求刪除：輸入指令「刪除 [對象名稱]」可立即移除該對象的所有紀錄。

終止服務：您可以隨時透過 LINE 介面「封鎖」本帳號，這將停止後續所有資料收集。

六、 聯絡我們
若對本政策有任何疑問，或需要手動申請清空個人資料，請透過 LINE 訊息與開發者聯繫。
